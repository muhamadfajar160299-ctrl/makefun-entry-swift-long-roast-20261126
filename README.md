# The Long Roast: Lawmakers and the File They Cannot Convert

One satirical sentence roasting lawmakers who would regulate AI, crypto or the internet but cannot convert a file to PDF.

> The chairman of the committee writing the rules for artificial intelligence just photographed his laptop screen and emailed the picture to his aide asking her to turn it into a PDF.

`main.py` (Python standard library only, deterministic, no network) writes this sentence to `entry.txt` in the directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`).
